# Cabinet Stories

How real people use Cabinet. <mark data-color="amber">These cards are illustrative examples</mark> for now — the page is wired to swap in real Discord, X, and GitHub quotes as they come in. Filter by the kind of work or the channel the story comes from.

<div data-demo="stories"></div>

## Have your own?

Post on X with <span class="tx-accent">#mycabinet</span>, drop it in <a href="https://discord.gg/hJa5TRTbTH">Discord</a>, or open a PR against the stories file in this docs cabinet. Best stories get featured.

## What we look for

- A <mark data-color="yellow">specific persona</mark> — "solo founder," "PhD candidate," "two-person agency," not "professional."
- A <mark data-color="green">specific outcome</mark> — what the cabinet does that you used to do by hand.
- A <mark data-color="blue">specific surface</mark> — agents, heartbeats, child cabinets, templates, BYOAI. Helps people picture which feature to try first.
