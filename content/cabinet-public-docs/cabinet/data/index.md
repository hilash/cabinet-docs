# Data

The Data tab is <mark data-color="yellow">**your file tree**</mark>. Whatever lives in your cabinet folder shows up here, in the same order, with first-class viewers for the formats you already use.

## What you can put in a cabinet

**<span class="tx-amber">Notes.</span>** Plain markdown. Cabinet's editor gives you a slash menu, wiki-links, mentions, callouts, math, color, and source mode when you want it.

**<span class="tx-purple">Office files & PDFs.</span>** Word, Excel, PowerPoint, Google Workspace exports, and PDFs render inline — no download dance.

**<span class="tx-accent">Data files.</span>** CSVs render as tables. Source code renders with syntax highlighting. Mermaid diagrams render as diagrams.

**<span class="tx-green">Media.</span>** Images, video, and audio play in place. Embedded apps (HTML / web bundles) run as live panels.
